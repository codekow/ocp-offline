# Agenda

## Day1

### Observability & Logging

- OpenShift Logging Operator

  - Review current logging architecture and operator configuration
  - Splunk integration walkthrough
  - Validate platform and application logs in Splunk

- Cluster Observability Operator (COO)

  - Review current COO setup and architecture
  - Multi-cluster observability for platform and applications
  - Validate internal application logs
  - Validate internal platform logs
  - ITO Grafana integration overview
  - Telegraf agent vs operator-based approach

### Security & Compliance

- Advanced Cluster Security (ACS)

  - Review ACS deployment and policies
  - Binary authorization strategy
  - Image signing and verification using Cosign

### Storage & Persistent Volumes

- Persistent Volume (PV) Support

  - How do persistent volumes work in OpenShift
  - Supported storage options for application teams
  - NFS support model
  - Mount options
  - Operational and security considerations

### Backup & Disaster Recovery

- Backups and Recovery Options

  - Review backup and recovery requirements
  - Internal supported tools and platforms (if available)
  - Alignment on recommended backup patterns

## Day 2

### Service Mesh

- Service Mesh Validation

  - Review current Service Mesh deployment and configuration
  - Ingress/Egress patterns
  - Gateway and Virtual Service design
  - Validation of traffic flow and operational model

### Platform Sizing & Isolation

- Sizing Review

  - Review current cluster sizing assumptions
  - Resource allocation and growth considerations
  - Dedicated cluster discussion (e.g., MyQ use case)
  - Isolation strategies between clusters (security, network, workload)

### Network & Firewall Requirements

- Production Firewall Ports

  - Review ACL firewall requirements
  - Required ports for:
  - Core OpenShift platform
  - Operators and integrations
  - Alignment with production security standards

### CI/CD Enablement

- CI/CD Deployments

  - Review current application deployment pipelines
  - Integration with OpenShift
  - Best practices and recommended deployment patterns

### Upgrade & Lifecycle Management

- Upgrade Testing

  - Review current OpenShift version
  - Upgrade path to target version
  - Lab readiness for upgrade testing
  - Validation and rollback considerations

## Day 3

- CP4i Review

  - Review current CP4i install and configuration
  - DataPower Install
  - Install DataPower Operator and configure
  - Validate test cases
